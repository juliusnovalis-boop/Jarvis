 J.A.R.V.I.S. — AGENT PC : INSTALLATION
═══════════════════════════════════════════════════════════════

★ MÉTHODE LA PLUS SIMPLE (Windows) : L'INSTALLATEUR
  Téléchargez JarvisAgent-Setup.exe depuis l'interface Jarvis
  (onglet Système). Contient : Python embarqué, toutes les
  dépendances et les modèles vocaux. AUCUNE autre installation.

  L'installateur :
    • installe dans %LOCALAPPDATA%\Programs\JarvisAgent
    • crée un raccourci « Jarvis » sur le bureau et le menu Démarrer
    • lance Jarvis en arrière-plan à chaque ouverture de session
    • inscrit un désinstallateur propre dans « Programmes et fonctionnalités »
  L'adresse du cerveau Jarvis est lue depuis app\server_url.txt
  (modifiable à tout moment si votre serveur change d'adresse).

  Windows SmartScreen peut demander confirmation (« Exécuter »),
  le programme n'étant pas signé par un éditeur certifié.

★ MÉTHODE SOURCE (Windows, Linux, macOS) : Python + ce script

PRÉREQUIS
  Python 3.10 ou plus : https://www.python.org/downloads
  (Windows : cochez bien "Add Python to PATH" pendant l'installation)

ÉTAPE 1 — Dépendances
  pip install pyautogui requests pillow ddgs
  pip install openwakeword sounddevice numpy      <-- mot-clé vocal « Jarvis »

  (Linux : sudo apt install portaudio19-dev  si sounddevice refuse de s'installer)

ÉTAPE 2 — Lancement (copiez l'URL exacte affichée dans l'onglet Système de Jarvis)
  python jarvis-agent.py --server https://VOTRE-URL-JARVIS

  L'agent s'enregistre, tourne EN ARRIÈRE-PLAN, se reconnecte
  automatiquement et garde sa configuration dans ~/.jarvis-agent.json
  (les lancements suivants se font sans --server : python jarvis-agent.py)

ÉTAPE 3 — Démarrage automatique à l'ouverture de session (optionnel)
  python jarvis-agent.py --autostart
  (Windows : registre Run / macOS : LaunchAgents / Linux : systemd --user)

🎙️ OUVRIR JARVIS À LA VOIX (mot-clé « Jarvis »)
  L'agent écoute le micro en permanence, 100 % hors ligne (openWakeWord,
  modèle pré-entraîné « hey_jarvis »). Aucun son ne quitte votre PC.

  Dites simplement :  « Jarvis »  ou  « Hey Jarvis »
    1. le PC répond à voix haute « Oui monsieur, je vous écoute »
    2. votre navigateur s'ouvre sur Jarvis, déjà démarré et à l'écoute

  Réglages :
    --wake-threshold 0.08   seuil par défaut, calibré pour une voix française
                            (montez à 0.15 si déclenchements intempestifs,
                             descendez à 0.05 si Jarvis ne vous entend pas)
    --no-wake               désactive complètement l'écoute du mot-clé

  VÉRIFIER SANS PARLER (autotest) :
    python jarvis-agent.py --selftest mon_enregistrement.wav
    (WAV 16 kHz mono ; un fichier nommé neg_*.wav est attendu NON détecté)

  Mesures de référence obtenues en laboratoire sur voix de synthèse :
    « hey jarvis » (EN) 0.998 | « Jarvis » (FR) 0.429 | « Jarvis ! » 0.207
    « Jarvis, allume la lumière » 0.139
    Bruit de fond / phrases courantes : 0.000 à 0.016
    -> 17 échantillons testés, 17 verdicts corrects, 0 faux positif.

COMMANDES VOCALES POSSIBLES UNE FOIS L'AGENT EN LIGNE
  « déplace la souris à droite de 400 »      souris
  « centre la souris » / « double-clic »     souris
  « tape bonjour au clavier »                clavier
  « exécute la commande dir »                console du PC
  « ouvre mes documents »                    fichiers
  « ouvre le bloc-notes »                    applications
  « ouvre rapport.pdf sur le pc »            recherche + ouverture de fichier
  « fais une capture d'écran »               capture renvoyée et affichée
  « verrouille le pc »                       session
  « éteins le pc » / « annule l'extinction » extinction avec délai annulable

SÉCURITÉ
  • La souris poussée dans le coin HAUT-GAUCHE de l'écran provoque
    un arrêt d'urgence de l'agent (FAILSAFE PyAutoGUI).
  • Les commandes destructrices connues sont bloquées ; --unsafe désactive.
  • Votre PC doit pouvoir joindre l'URL du serveur Jarvis (même Wi-Fi,
    ou serveur exposé en HTTPS).
